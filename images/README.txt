Panduan Menambahkan Gambar Produk ByDelune:

1. Simpan foto produk Anda di dalam folder ini (images/).
   Contoh penamaan file:
   - produk-1.jpg
   - produk-2.webp
   - hero-banner.jpg

2. Rekomendasi Format & Ukuran (Quiet Editorial Standard):
   - Rasio Aspek: 3:4 (contoh: 900 x 1200 pixel atau 600 x 800 pixel)
   - Format: .webp atau .jpg (terkompresi agar loading website cepat)
   - Nuansa Foto: Latar belakang bersih/studio minimalis (alabaster, stone, putih gading)

3. Cara Memanggil Gambar di index.html:
   Ganti atribut src pada tag <img> dengan:
   src="images/produk-1.jpg"
